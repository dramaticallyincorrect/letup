Letup let's you build mini apps that run in the browser using conversation with an ai agent. apps you build have access to a database to store data across session and devices. apps can bring in external libraries and make http requests. You can also make apps that use agents, just let the ai know if you want something done with an agent and the ai will handle the integration.
You can install these apps as pwas and launch them directly from your computer.
